统一管理 API

用一套稳定、可审计的 HTTP API 管理阿里云、腾讯云、Cloudflare、魔方财务等服务商资源。服务商密钥始终保存在塔维云服务端，不会通过本 API 返回。

示例地址
https://console.example.com/api/v1
请将示例域名和 API 密钥替换为你的实际配置。

认证与权限

在请求头中携带 API 密钥。密钥只在创建时显示一次，撤销后立即失效。

Authorization: Bearer tvr_replace_with_your_key
Accept: application/json
Content-Type: application/json
Scope允许访问
accounts.read读取已接入的服务商账号（不含凭据）
resources.read读取资源、详情和当前可用操作目录
resources.manage执行操作目录中的资源操作
sync.read读取同步任务和状态
sync.manage为指定账号创建同步任务

建议为每个自动化程序创建最小权限密钥。不要把密钥放入浏览器代码、前端仓库或日志。

响应格式

成功响应统一使用 code: 0。列表数据位于 data.items，详情数据位于 data。

{
  "code": 0,
  "message": "ok",
  "data": { "items": [], "pagination": { "page": 1, "per_page": 20, "total": 0, "last_page": 1 } }
}

失败时 HTTP 状态码与 code 一致，并可能返回字段级 errors：

{ "code": 422, "message": "Validation failed.", "errors": { "operation": "Unsupported operation." } }

分页与筛选

列表接口支持 page（从 1 开始）和 per_page（1 至 100，默认 20）。资源列表还支持以下筛选：

参数说明示例
provider_slug服务商标识cloudflare
cloud_account_id账号 ID12
resource_type资源类型instance
status资源状态active
region区域ap-shanghai

服务商账号

GET/accountsaccounts.read

读取账号列表。返回账号名称、服务商、区域、同步状态和时间，不返回 Access Key、Token 或密码。

curl -sS 'https://console.example.com/api/v1/accounts?page=1&per_page=20' \
  -H 'Authorization: Bearer tvr_replace_with_your_key'
POST/accounts/{accountId}/syncsync.manage

创建异步同步任务。重复请求不会并发创建同一账号的重复任务。

curl -sS -X POST 'https://console.example.com/api/v1/accounts/12/sync' \
  -H 'Authorization: Bearer tvr_replace_with_your_key' \
  -H 'Content-Type: application/json' --data '{}'

成功返回 202 和 data.sync_job_id。

资源目录

GET/resourcesresources.read

读取标准化资源目录。每项包含系统内部 id、服务商侧 external_id、资源名称、类型、区域和状态。

curl -sS 'https://console.example.com/api/v1/resources?provider_slug=tencent-cloud' \
  -H 'Authorization: Bearer tvr_replace_with_your_key'
GET/resources/{resourceId}resources.read

读取单个资源及经过处理的摘要字段。可能包含 IP、操作系统、规格、到期时间和服务商提供的 CPU/内存/磁盘指标；密码永远不会返回。

资源操作

GET/resources/{resourceId}/actionsresources.read

获取该资源当前真实可用的操作目录。每个操作包含 id、显示名称、是否危险、输入字段和只读标记。不要自行猜测服务商能力；魔方财务和 IDCsmart V10 会先读取产品控制面板。

curl -sS 'https://console.example.com/api/v1/resources/42/actions' \
  -H 'Authorization: Bearer tvr_replace_with_your_key'

下拉字段必须使用接口返回的 options[].value。例如重装系统的 os_id 必须使用服务商返回的操作系统 ID。

POST/resources/{resourceId}/actionsresources.manage

执行操作目录中的一个操作。危险操作必须把资源完整名称放入 confirmation。密码等一次性字段只用于本次请求，不会写入审计日志。

curl -sS -X POST 'https://console.example.com/api/v1/resources/42/actions' \
  -H 'Authorization: Bearer tvr_replace_with_your_key' \
  -H 'Content-Type: application/json' \
  --data '{"operation":"start","parameters":{}}'

重装系统示例

{
  "operation": "reinstall",
  "parameters": { "os_id": "provider-returned-os-id", "password": "one-time-new-password", "part_type": 0 },
  "confirmation": "资源完整名称"
}

Cloudflare DNS 示例

{
  "operation": "create_dns_record",
  "parameters": { "type": "A", "name": "app.example.com", "content": "203.0.113.10", "ttl": 300, "proxied": true }
}

服务商成功响应会返回经过处理的摘要；异步变更通常附带 sync_job_id。VNC/KVM 等控制台操作只会返回安全的 HTTP(S) 地址。

同步任务

GET/sync-jobssync.read

查询同步任务，支持 status=queued|running|succeeded|failed。

curl -sS 'https://console.example.com/api/v1/sync-jobs?status=failed&page=1' \
  -H 'Authorization: Bearer tvr_replace_with_your_key'

错误码与重试

HTTP含义处理建议
400请求格式错误检查 JSON 和 Content-Type
401密钥缺失、无效或已撤销重新创建 API 密钥
403缺少所需 Scope 或服务商权限调整 API 密钥或上游 Token 权限
409危险操作确认不匹配或状态冲突使用资源完整名称并重新读取资源状态
422参数或操作不合法以当前操作目录的字段和 options 为准
429请求过于频繁按指数退避重试
502/503上游服务商或同步服务暂时不可用只读请求可稍后重试，写操作不要盲目重复提交

建议对 429、502、503 使用 1、2、4、8 秒退避；危险操作收到超时后先查询资源状态和同步任务，不要直接重复执行。
